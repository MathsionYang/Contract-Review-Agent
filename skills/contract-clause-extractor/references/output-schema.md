# 输出 JSON 结构规范

## 完整结构

```json
{
  "合同名称": "",
  "合同编号": "",
  "采购方": {
    "名称": "",
    "统一社会信用代码": "",
    "法定代表人": "",
    "住所": "",
    "联系人": "",
    "联系电话": ""
  },
  "供货方": {
    "名称": "",
    "统一社会信用代码": "",
    "法定代表人": "",
    "住所": "",
    "联系人": "",
    "联系电话": ""
  },
  "前言": "",
  "条款": [
    {
      "条款编号": "第一条",
      "原文编号": "第一条",
      "标题": "定义",
      "类型": "定义",
      "起始页": null,
      "子条款": {
        "1.1": "原文内容",
        "1.2": "原文内容"
      }
    }
  ],
  "签署页": {
    "甲方": "",
    "乙方": "",
    "签约日期": ""
  },
  "异常清单": [
    {
      "类型": "",
      "位置": "",
      "描述": "",
      "建议": ""
    }
  ]
}
```

## 字段语义

### 顶层

| 字段 | 取值 | 说明 |
|---|---|---|
| `合同名称` | string | 合同标题原文（如"采购合同"），不自行补全成"XX 采购合同" |
| `合同编号` | string | 原文编号，含前缀与分隔符，原样搬运 |
| `前言` | string | 鉴于条款 / 引言全文合并为一段，保留原文标点 |
| `条款` | array | 按原文顺序，**一章/一条一个对象** |
| `异常清单` | array | 未发现异常时输出 `[]`，不要省略字段 |

签订地点、签订日期若原文有，则**追加为顶层键**（`签订地点`、`签订日期`），同名于 `签署页.签约日期` 时以签署页为准。

### 双方主体

只在原文出现时填值；缺失留空字符串 `""`。多个联系人/电话用 `、` 连接，不要拆成数组。
若原文写作"买方 / 卖方"或"委托方 / 受托方"，仍映射到 `采购方` / `供货方` 两个键，**不要新增键名**。

### 条款对象

| 字段 | 说明 |
|---|---|
| `条款编号` | 规范化编号。原文"第 5 条"→ `第五条`；原文"一、"→ `第一条`；原文"1."→ `1` |
| `原文编号` | 原样保留，不做任何规范化（这是重复编号检测的依据） |
| `标题` | 条标题，如"违约责任"。原文无标题则填 `""` |
| `类型` | 从 22 类中选一个，判定线索见 `clause-taxonomy.md` |
| `起始页` | 来源为 PDF 时填该条**首个字所在页码**；docx 来源填 `null` |
| `子条款` | 对象，键 = 原文子编号（`1.1`、`（1）`、`a）` 原样），值 = 该子条款原文全文 |

子条款处理约定：

- 无子条款时输出 `{}`，不要省略键、也不要填 `null`。
- 条标题之后、第一个子编号之前的无编号段落，用 `"其他"` 作为键。
- 紧跟在某子条款之后的无编号段落，**归入上一子条款**，拼接到该子条款文本末尾。
- 子条款原文含表格时，表格转 Markdown 后作为该子条款的文本内容（换行用 `\n`）。

### 签署页

`甲方` / `乙方` 填签署方名称（可含"（盖章）"等原文标注），`签约日期` 填原文日期字符串。多页签署时按出现顺序拼接。

### 异常清单

| 字段 | 说明 |
|---|---|
| `类型` | 见下表明细，用固定中文短语 |
| `位置` | **必须可定位**：写"条款编号 + 子条款号"，如 `第九条 9.1`；跨条款的写两处，用" / "分隔 |
| `描述` | 客观陈述事实，不带评价词 |
| `建议` | 形式层面的修复动作，一句话 |

`类型` 取值（16 项检查对应，详见 `anomaly-checks.md`）：

```
条款编号重复 / 条款编号跳号
子条款编号重复 / 子条款编号跳号
交叉引用不存在 / 交叉引用歧义
金额大小写不一致
含税与不含税冲突
交付与验收时间冲突
风险转移冲突
质保期起算点不明确
违约责任不对等
仲裁与诉讼并存
仲裁终局性表述矛盾
合同解除条件不明确
知识产权或数据条款不明确
生效日期异常
附件缺失
主体表述错误
```
