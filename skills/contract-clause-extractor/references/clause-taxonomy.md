# 条款分类线索（22 类）

分类只用于填 `类型` 字段，**不改变输出顺序、不合并条款**。

## 判定优先级

1. **看标题**：标题命中关键词表 → 直接归类。
2. **看内容主体义务**：标题为空或笼统（"其他""一般条款"）时，按该条承担的**主要义务**归类。
3. **多主题条款**：一条涵盖多个主题时，按**第一个实质义务**归类，不要拆条。
4. **兜底**：以上都不匹配 → `其他约定`。

| `定义` | 定义、术语、释义 | 通篇 `X.1 "术语"指…` 格式 | 与"其他约定"下的释义段区分：有"指/系指"才算定义 |

## 编号体系识别

按以下顺序识别条级编号，**先匹配到的优先**：

| 层级 | 形态 | 归一化示例 |
|---|---|---|
| 章 | `第一章`、`第 1 章`、`一、`（章级） | 章内条号独立起算 |
| 条 | `第一条`、`第 1 条`、`第1条` | `条款编号` → `第一条` |
| 条（数字式） | `1.`、`1、`、`1 ` | `条款编号` → `1` |
| 款 | `1.1`、`1.1.1` | 作为 `子条款` 的键 |
| 款（括号式） | `（1）`、`(1)`、`1）` | 键原样保留 |
| 款（字母式） | `a)`、`A.` | 键原样保留 |

要点：

- `条款编号` 做**归一化**（"第 1 条" → "第一条"），`原文编号` 做**原样保留**——重复检测依赖后者。
- **中文序数与阿拉伯数字可能混用**：标题用"第一条"，正文引用却写"第 1.4 条"。抽取时两套都要能认，否则引用会漏（见 `anomaly-checks.md` 第 3 项）。
- 编号后跟**全角空格 `　`** 是常见排版，不影响切分；不要因此把标题并进正文。
- 自动编号列表（Word 的 numbering）导出文本时可能丢失编号，此时按**段落位置 + 上下文**推断条级起点，并在异常清单提示"原文为自动编号，编号可能不可靠"。
