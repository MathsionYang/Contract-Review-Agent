# 合同审查 Agent 前端原型

## 概述

这是一个基于需求文档《中国大陆企业内部合同审查 Agent 需求说明 v0.4》设计的可运行前端原型，展示了合同审查系统的核心工作流程。

## 核心功能

### 1. 首页（工作概览）
- **统计面板**：展示待处理任务、进行中任务、已完成任务和发现风险项的数量
- **最近任务列表**：显示最近的审查任务，包括状态、合同类型、风险数量等信息
- **快速操作**：上传新合同按钮，快速开始审查流程

### 2. 审查工作台（三栏布局）
原型的核心功能，实现了完整的"合同导入 → 解析/审查 → 风险确认 → 结果导出"工作流：

#### 左侧：合同目录
- 展示合同条款结构
- 点击可快速跳转到对应章节
- 支持导航定位

#### 中间：合同正文
- 展示合同原文内容
- 风险位置高亮标注（严重/高/中/低不同颜色）
- 支持工具栏操作：
  - 🖱️ 选区审查：选择文本进行局部审查
  - 💬 添加批注：为选中内容添加批注
  - 📥 导出报告：导出审查结果
  - 🔄 刷新：刷新审查状态

#### 右侧：风险清单面板
- 实时展示识别的风险项（8个样本风险）
- 风险卡片包含：
  - 风险等级徽章（严重/高/中/低）
  - 风险标题和描述
  - 风险位置定位
  - 快速操作按钮（接受/驳回）
- 点击风险卡片查看详细信息

### 3. 风险详情弹窗
- **风险等级和分类**：显示风险等级、类别标签
- **风险位置**：精确定位到合同条款和页码
- **置信度**：显示 AI 审查的置信度
- **风险说明**：详细描述风险内容
- **法律依据**：展示相关法律法规条文
- **修改建议**：提供具体的修改建议
- **处理记录**：显示创建人、创建时间、处理状态
- **操作按钮**：标记误报、修改、关闭

### 4. 合同上传弹窗
- 项目名称输入
- 合同类型选择（采购/供应商服务/销售客户服务/房屋租赁/软件开发）
- 文件上传（支持 DOCX、PDF，最大 50MB）
- 审查模式选择：
  - 标准审查（使用法律知识快照）
  - 实时核查（查询最新法律来源）

### 5. 导出报告弹窗
- **导出格式选择**：
  - DOCX 审查报告
  - PDF 审查报告
  - XLSX 风险清单
  - JSON 结构化数据
- **包含内容选择**：
  - 合同正文与高亮标注
  - 风险分析与建议
  - 法律依据与证据
  - 人工处理记录

### 6. 管理视图（占位）
- 📁 项目列表
- 📚 知识库管理
- 🔧 Skill 管理
- 🤖 模型配置
- 📊 审计日志
- ⚙️ 系统设置

## 核心工作流演示

### 流程1：查看现有审查任务
1. 进入首页，查看工作概览和统计数据
2. 点击任务列表中的"【采购合同】ABC公司办公设备采购合同"
3. 自动跳转到审查工作台
4. 查看三栏布局：目录、正文、风险清单

### 流程2：风险确认和处理
1. 在审查工作台右侧查看风险清单（8个样本风险）
2. 点击任意风险卡片，查看详细信息
3. 在弹窗中查看：
   - 风险等级、类别、位置
   - 风险说明和法律依据
   - 修改建议和处理记录
4. 使用快速操作按钮：
   - 点击"✓ 接受"接受风险
   - 点击"✗ 驳回"驳回风险
   - 点击"标记误报"标记为误报

### 流程3：选区审查
1. 在合同正文区域选择任意文本
2. 点击工具栏"🖱️ 选区审查"按钮
3. 系统模拟局部审查过程
4. 审查完成后显示通知

### 流程4：导出审查报告
1. 点击工具栏"📥 导出报告"按钮
2. 在弹窗中选择导出格式（DOCX/PDF/XLSX/JSON）
3. 选择包含的内容
4. 点击"导出"按钮
5. 系统模拟生成报告并下载

### 流程5：上传新合同
1. 在首页点击"📤 上传新合同"按钮
2. 填写项目名称
3. 选择合同类型
4. 上传合同文件
5. 选择审查模式
6. 点击"开始审查"
7. 系统模拟创建审查任务

## 样本数据说明

### 合同示例
原型包含一个完整的采购合同样本：
- **合同名称**：ABC公司办公设备采购合同
- **合同类型**：采购合同
- **合同编号**：CG-2026-0910-001
- **页数**：1页
- **条款数**：7条主要条款

### 风险示例
预置了8个典型风险项，覆盖不同风险等级和类别：

| 风险ID | 等级 | 类别 | 主题 | 标题 |
|--------|------|------|------|------|
| risk_001 | 严重 | 法律风险 | 违约责任 | 违约责任条款失衡 |
| risk_002 | 高 | 商业风险 | 付款条件 | 付款条件与验收标准存在风险 |
| risk_003 | 高 | 文本质量 | 交叉引用 | 附件引用缺失 |
| risk_004 | 中 | 商业风险 | 质量保证 | 质保期责任范围不明确 |
| risk_005 | 中 | 文本质量 | 金额一致性 | 金额表述不一致 |
| risk_006 | 中 | 企业制度 | 审批权限 | 预付款比例超出公司制度 |
| risk_007 | 低 | 文本质量 | 争议解决 | 争议解决条款可优化 |
| risk_008 | 低 | 文本质量 | 签字 | 授权代表签字条款不完整 |

每个风险都包含：
- 风险描述
- 合同定位（条款号、页码）
- 法律依据（部分风险）
- 修改建议
- 置信度
- 处理状态
