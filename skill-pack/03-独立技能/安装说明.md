## 验证安装

```bash
cd ~/.workbuddy/skills/tencent-esign-contract
python3 scripts/tencent_esign.py version      # 脚本可用性
python3 scripts/tencent_esign.py auth-check   # token 状态
```

## 首次配置 Token

```bash
python3 scripts/tencent_esign.py auth-validate <你的 SIGN-TOKEN>
```

Token 获取地址：`https://qian.tencent.com/aiSkill`。校验通过后自动写入 `~/.esign-token`（权限 600），**该文件与专家会话共享**，即此前的鉴权结果在这里同样生效，无需重复配置。

## 更推荐的安装方式（可更新）

当前安装是**从本地插件目录复制**，无法随上游更新。若希望后续能一条命令升级，改用官方仓库克隆：

```bash
git clone https://github.com/tencentess/tencent-esign-contract.git ~/.workbuddy/skills/tencent-esign-contract
cd ~/.workbuddy/skills/tencent-esign-contract && git pull   # 后续更新
```

> 注意：`git clone` 前需先删除现有同名目录，两者只能存在其一。上游仓库比插件内置副本更完整，额外包含 `evals/evals.json`（25 个测试场景）、`scripts/pack.sh`、`scripts/test_evals.py`。

## 安全审计说明

| 检查项 | 结论 |
|---|---|
| 来源可信度 | 腾讯官方开源项目（MIT），内容与已安装专家插件内技能字节一致 |
| 脚本行为 | 单文件 Python CLI：读写 `~/.esign-token`、上传用户指定文件至腾讯电子签 API、下载导出文件至本地 `downloads/` |
| 无隐藏行为 | 未发现外联非腾讯域名、未发现批量扫描或改删用户文件、无持久化后台进程 |
| 建议 | 可安全使用；上传文件前确认该合同不含不愿上传至云端的敏感内容 |

## 回滚

```bash
rm -rf ~/.workbuddy/skills/tencent-esign-contract
```

删除后专家会话内的原技能不受影响；如已配置 token，`~/.esign-token` 也会保留，可继续使用。
