## 2. 缺口清单

### A. 风险清单筛选/排序/批量操作
1. **仅按等级过滤**：`filteredRisks` 只比较 `risk_level`（ReviewWorkspace.vue:55，下拉 548）。`risk_category/risk_topic/human_status/evidence_status/tag` 均无过滤入口（全仓库 `risk_topic` 仅出现在数据与 store，UI 零引用）。影响：几百条风险时无法聚焦"待人工确认""证据未核验"子集。建议：多条件过滤栏 + 标签过滤。
2. **无排序**：列表按数组原始顺序渲染（551），无按等级/置信度/页码/更新时间排序（FR-143、需求 871 行要求"按风险等级排序"仅在导出侧）。建议：排序选择器 + 默认严重度优先。
3. **无批量操作**：无多选 checkbox、无批量接受/驳回/延期（列表仅卡片内 4 个单键 557-560）。影响：法务逐条点击成本随风险数线性上升。建议：多选 + 批量处理 + 结果汇总。
4. **缺"驳回"动作**：store 仅映射 accepted/false_positive/modified/deferred/deleted（review.js:225），FR-041 显式要求"驳回、暂不处理、人工新增"；UI 无独立驳回键。建议：补齐 action 枚举与按钮。
5. **空态语义错误**：`v-if="!filteredRisks.length"` 统一提示"暂时没有风险项"（563），筛选无结果时文案误导。建议：区分"无风险/筛选无匹配"。
6. **AI 原始结果无只读视图**：卡片/详情无"原始 AI 结论"对照，仅靠 store 内 `humanRevisions` 留痕（review.js:230-241），FR-043 的"只读保留"在界面上不可见。

### B. 风险定位与原文对照闭环
1. **反向导航缺失**：原文 `<mark>` 仅 `data-risk` 可点（209-212）；点风险后清单无"已定位"回执，也无"上一条/下一条风险"步进（无任何快捷键/tabindex）。影响：跨页复核需反复滚动。
2. **人工高亮不可回跳**：`data-annotation` 被写入但点击处理未读取（154 vs 209-212），而 CSS 给了 `cursor:pointer`（styles.css:259）——可点击暗示与实际行为不符，属于交互缺陷。
3. **无原文对照视图**：详情面板只给 quote 文本（584），无并排/上下文段落对照，也无"复制引用"。FR-024 的"上下文"未呈现。
4. **定位失败态不完整**：`locationLabel` 对 unresolved/fallback 返回"待定位"（checklistReview.mjs:28），但风险卡"待定位"风险与正常风险视觉等同，无"无法精确定位"专门样式与批量定位失败统计（FR-025）。
5. **搜索范围仅当前页**：`searchQuery` 只匹配 `currentPage.text`（95-98、180-189），FR-143"全文搜索"未实现；每次输入即正则重匹配 + 重建整页 HTML（无防抖）。

### C. 人工修订入口与版本留痕
1. **不能修改等级/类别/主题/标题/分析/建议/依据**：详情面板全部是只读文本（584-588），FR-044/需求 813-814 要求的编辑入口完全缺失；"人工修改"按钮只把 `human_status` 置为 `modified`（review.js:225-239）。
2. **无撤销/回滚**：全仓库无 undo/revert，`humanRevisions` 只增不减，无历史查看/版本切换 UI；删除风险无二次确认且无恢复（581）。影响：误操作不可逆，违反 FR-043 精神。
3. **留痕字段不全**：`humanRevisions` 记录 `changes: {human_status}`、reason 自动生成"人工处理：accepted"（231-239），无用户填写的原因输入框，也未记录模型/规则/Skill/快照版本（FR-042/FR-046）。
4. **人工新增风险入口仅限选区**：`reviewSelection` 只能由划词触发（store:262-295），无表单式"新增风险"（含无法定位标记）。

### D. 键盘可达性与无障碍
1. **无中英切换/快捷键**：`handleEscape` 只关选区菜单（316-330），无 Esc 关详情面板/模态、无 j/k 或上下条风险导航、无 `tabindex`（全仓库 0 处）。
2. **焦点管理缺失**：Modal 无焦点陷阱、无自动聚焦、关闭后焦点不归还（Modal.vue:13-19），`aria-modal` 有但无 `focus()` 调用（全仓库 0 处）。
3. **危险动作零确认**：删除风险（581）、删除模型用浏览器 `window.confirm`（CapabilityView.vue:145），风格与 Modal 基线不一致。
4. **ARIA 覆盖不均**：`aria-*` 共 89 处、`role="alert"` 仅 1 处；校验失败/保存失败只发 toast（review.js:63、App.vue:136），屏幕阅读器优先级不足。
5. **动效与字号**：`prefers-reduced-motion` 零处理，`.spin` 无限旋转（styles.css:148）；`font-size` 硬编码 19px 级 71 处，无 UI 字号档位（仅文档区 zoom，store:216-218）。

### E. 大文档渲染与内存
1. **无虚拟滚动**：`risk-list` 全量 v-for（550-551），无 IntersectionObserver/windowing；标记合成对全部风险过滤（164-170），每次翻页/搜索整页重建。
2. **全量深拷贝持久化**：每次点击操作 `electronApi.saveState(state.value)` 经 `toCloneable` 递归克隆整个 state（含全部风险与页文本，clonePayload.mjs:4-41；review.js:220-244），无防抖/节流，长会话主线程阻塞风险高。
3. **翻页仅前后/下拉**（486-488），缺页码跳转、条款目录；无文档体积/条款数超限提示（需求 1928 行明确要求分段按需加载）。

### F. 空态/加载态/错误态/超时
1. **首屏无骨架/加载态**：`bootstrap()` 期间无任何 loading UI（App.vue:48、review.js:67-125），仅在完成后渲染，`isReady` 仅被 Dashboard 用于禁用按钮（DashboardView.vue:14）。
2. **失败不可重试**：`persist()` 失败仅 toast（review.js:63）；`runValidator` 失败留 `validatorResult=null`（App.vue:130-141），导出弹窗不显示重试键；校验中切换模式/格式无请求守卫，旧结果可覆盖新结果（210-211 每次 `@change` 触发 `validateExport`，无 requestId）。
3. **无超时 UI**：模型层有 `timeoutMs`（CapabilityView:271），但对话/审查面板无超时倒计时、无超时后自动转失败态与重试入口。
4. **无离线/桥缺失态**：桥不可用时仅被动词条（electronApi.js:23 等），无顶部持久告警条。

### G. 状态同步与幂等
1. **读-改-写竞态**：`applyRiskAction` 直接改响应式对象后 `persist()`（review.js:220-244），期间无 `isBusy` 锁；连续操作两个风险时后一次请求可能覆盖前一次（saveState 为整状态替换，electronApi.js:105-112）。
2. **部分写操作无忙锁**：`deleteModel/toggleSkill/saveModel`（review.js:727-798）、`addKnowledge/updateKnowledge`（647-682）不检查 `isBusy`，可并发点击。
3. **逐条写入**：知识库"全选当前筛选"对每条 `await toggle`→各自 `saveConfig`（KnowledgeView.vue:147-152 + review.js:625-633），N 次全状态写；快照/审计/记忆 Tab 无多选批量。
4. **设置未生效**：`autoSave/autoSaveInterval` 可配（SettingsView.vue:88-89、sampleData.js:200-201）但渲染层持久化从不读取——FR-145"配置当前值/来源"要求的展示亦缺。

### H. 国际化/主题/可配置性
1. 全部文案硬编码中文，`toLocaleString("zh-CN")` 硬编码（DashboardView.vue:45、KnowledgeView.vue:334），无 i18n 框架与语言入口。
2. 无主题/深色模式切换（`styles.css:1 :root` 单套变量），无 UI 字号档位；`compactMode` 仅两级（AppShell.vue:32、SettingsView.vue:116）。

### I. 导出流程完整性
1. **无预览、无输出路径/文件名选择、无进度与取消**（App.vue:209-213）；`exportRecords` 存在于数据模型（sampleData.js:250）但全仓库无导出历史 UI（FR-142、需求 172/1825 行）。
2. **失败重试缺失**：`startExport` 失败仅保留弹窗（157-160），无重试按钮。
3. **校验阻断项不可跳转**：`item.riskId` 仅展示（ExportValidation.vue:28），无点击定位到风险。
4. **无导出后"打开文件/打开目录"入口**；`result.records` 只用于 toast 数量（App.vue:156、review.js:827）。
