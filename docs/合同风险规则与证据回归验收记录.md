## 关键修复

1. 统一使用 `block_id`、`clause_no`、`char_range`、`quote` 和 `text_hash` 绑定合同证据。
2. 重复短引文返回 `ambiguous` 和候选集合，不能静默选择第一处命中。
3. DOCX 表格单元格使用块自身条款号回退定位，避免金额明细证据为空。
4. `risk_level` 表示影响等级，`decision_confidence` 表示当前结论可信度；确定性冲突在证据有效时保留规则等级。
5. 金额、税务、争议和验收主题按 canonical issue 聚合，保留相关规则、风险、条款和全部证据。
6. 违约金关系使用主体、违约事件、费率基数和累计上限判断，不依赖某一份合同的固定条款号。
7. 模型风险必须通过本地原文回放校验；非法引用记录 `MODEL_EVIDENCE_INVALID`，不回退到首页或任意页码。
8. 通用清单区分 `conflict`、`missing_candidate`、`unverifiable` 和 `not_applicable`，避免把材料不足误报为合同缺陷。

## 解释边界

自动化回归证明的是解析、规则、证据绑定和输出门禁的一致性，不等于法律意见或业务决策。正式报告仍需人工核对合同原件、附件、外部材料、适用法律版本和业务立场。
