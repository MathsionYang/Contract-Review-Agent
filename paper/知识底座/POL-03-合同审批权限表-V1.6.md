# 合同审批权限表（V1.6）

## 第 1 条　总则

**1.1** 本表依据《合同管理办法》（POL-CON）第 7.4 条制定，明确各类合同的审批层级与签署授权范围。

**1.2** **授权不可转授**。各级审批人应在授权范围内行使审批权，不得向下转授；因故无法履职的，由**上一级**代为行使。

**1.3** 审批权限以**合同金额**为基本维度，叠加**事项类型**维度。两者冲突时，按**更严标准**执行。

**1.4** 金额口径：
1. 以**合同总价（含税）** 为准；
2. 框架合同按**年度预计总额**计；
3. 可续期合同按**单个合同期的金额**计；
4. 同一项目分次签约的，按**累计金额**计。

**1.5（编号体系）** 本表条款采用"条—款"两级结构：`第 N 条` 为一级，其下的 `N.1`、`N.2` 为二级。对外引用统一写作 `POL-AUTH-N.x`（例：第 3 条第 1 款引作 `POL-AUTH-3.1`，第 4 条第 6 项引作 `POL-AUTH-4.6`）。本表第 4 条的 4.1–4.11 各项**同为二级条款**，引用规则相同。

## 第 2 条　授权层级

| 层级 | 角色 | 授权范围 |
| --- | --- | --- |
| L1 | 采购部/业务部门负责人 | 单项 < 5 万元的简式合同 |
| L2 | 分管副总 | 单项 5 万（含）–100 万元 |
| L3 | 总经理 | 单项 100 万（含）–500 万元 |
| L4 | 总经理办公会 | 单项 ≥ 500 万元，及本表第 4 条全部特别事项 |

**签署授权**：L1、L2 层级的合同由取得**书面授权委托书**的部门负责人签署；L3 及以上由法定代表人或经其授权的签署人签署。

## 第 3 条　金额分级审批矩阵

### 3.1 采购类合同

| 金额区间 | 业务初审 | 财务会签 | 法务审查 | 审批 | 签署人 |
| --- | --- | --- | --- | --- | --- |
| < 5 万元 | 部门负责人 | — | 标准文本免审；非标准文本必审 | L1 | 部门负责人 |
| 5 万–50 万 | 部门负责人 | 需 | 需 | L2 | 部门负责人（授权） |
| 50 万–100 万 | 部门负责人 + 采购部 | 需 | 需 | L2 + 财务负责人 | 分管副总 |
| 100 万–500 万 | 部门负责人 + 采购部 | 需 | 需（财务会签） | L3 | 分管副总（授权） |
| ≥ 500 万 | 部门负责人 + 采购部 + 技术委员会 | 需 | 需（双人审查） | L4 | 法定代表人 |

### 3.2 销售类合同

| 金额区间 | 业务初审 | 财务会签 | 法务审查 | 审批 |
| --- | --- | --- | --- | --- |
| < 5 万元 | 部门负责人 | — | 标准文本免审 | L1 |
| 5 万–100 万 | 部门负责人 | 需 | 需 | L2 |
| 100 万–500 万 | 部门负责人 + 销售总监 | 需 | 需 | L3 |
| ≥ 500 万 | 部门负责人 + 销售总监 | 需 | 需（双人审查） | L4 |

**销售合同的特别关注**：付款条件（预收款比例）、交付期承诺、质保承诺、违约金上限、争议解决地。销售合同的风险方向与采购合同相反，**有利于我方的条款越多，越需确认可履行性**。

### 3.3 服务、租赁及其他类

| 类型 | 审批层级 |
| --- | --- |
| 单次服务合同 | 按金额适用 3.1 或 3.2 |
| 长期服务/租赁（> 1 年） | 按累计金额上浮**一级**审批 |
| 借款、担保、股权、知识产权转让 | **一律 L4**（不受金额限制） |

## 第 4 条　特别事项上升审批

下列事项**无论金额大小**，均须上升至 **L4（总经理办公会）** 审批，并**必须**取得法务部意见：

| 编号 | 事项 | 上升原因 | 附加要求 |
| --- | --- | --- | --- |
| **4.1** | 与关联方（含董监高及其近亲属控制的企业）签订合同 | 存在利益输送风险 | 关联关系书面披露 + 独立价格公允性说明；关联董事回避 |
| **4.2** | 涉外合同（对方为境外主体，或履行地/标的在境外） | 法律适用、执行难度、外汇与出口管制 | 外部律师意见 + 法律适用与争议解决条款审查 |
| **4.3** | 担保、抵押、质押、保证 | 形成或有负债 | 外部律师意见 + 反担保安排或对价说明 |
| **4.4** | 知识产权转让、独占许可、技术出口 | 涉及核心资产 | 技术评估 + 外部律师意见 |
| **4.5** | 独家代理、排他性合作、竞业限制 | 限制经营自由 | 期限上限（不超过 3 年）+ 退出机制 |
| **4.6** | 预付款比例超过 `POL-PUR-9.2` 上限，或约定全额预付 | 资金风险 | 须提供预付款保函或等价担保；无担保的须说明必要性 |
| **4.7** | 接受对方 P0 级风险条款且对方拒绝修改 | 重大权利让渡 | 逐条说明接受理由 + 风险敞口测算 + 补救措施 |
| **4.8** | 无合同先履行后补签、先盖章后补审批 | 流程失控 | 说明原因 + 补办完整审批 + 责任人认定 |
| **4.9** | 承认对方索赔、放弃我方权利、达成和解 | 处分实体权利 | 金额测算 + 诉讼/仲裁胜算评估 |
| **4.10** | 变更已生效合同的核心条款（金额、期限、责任、争议解决） | 等同重新签约 | 按新签合同标准重新履行全部审批 |
| **4.11** | 合同期限超过 3 年，或自动续期条款 | 长期绑定风险 | 设置退出机制与年度复核条款 |

## 第 5 条　授权委托管理

**5.1（授权形式）** 授权委托书应载明：被授权人姓名与职务、授权事项范围、授权金额上限、授权期限、是否可转授权、签发日期与法定代表人签章。

**5.2（授权期限）** 单次授权不超过 **1 年**；到期自动失效，需续期的重新签发。

**5.3（授权登记）** 授权委托书由法务部统一编号登记，并在用印管理岗备案。**未备案的授权不得用于签署合同**。

**5.4（对外出示）** 签署时对方要求核验的，应出示授权委托书原件或加盖公章的复印件；我方应同时取得对方**签署人的授权证明**（对方为法人的，核验法定代表人身份或授权委托书）。

**5.5（越权签署的处理）** 无授权或超越授权范围签署的合同，公司可主张对被代理人不发生效力（`LAW-CIVIL-503`）；但已开始履行或接受对方履行的，**视为追认**。因此：
1. 业务部门不得以"对方越权"为由拒收已到货物；
2. 应立即启动内部追责，并在 5 个工作日内向法务部报告。

## 第 6 条　审批单要素

审批记录（纸质或系统流程）应至少包含：

| 字段 | 说明 |
| --- | --- |
| 合同编号与名称 | — |
| 对方名称与统一社会信用代码 | 须与核验结果一致 |
| 合同金额（含税） | 大写 + 小写 |
| 合同期限与关键日期 | 签署、生效、交付、验收、付款、质保到期 |
| 风险等级汇总 | P0 / P1 / P2 / P3 各若干 |
| **P0 风险处理情况** | 是否已修改；未修改的，接受理由 |
| 法务审查意见 | 通过 / 修改后签署 / 不建议签署 |
| 财务会签意见 | 涉资金、税务时必备 |
| 特别事项标记 | 是否触发第 4 条，触发哪几项 |
| 审批人签署与日期 | 逐级签署，不得代签 |
| 附件清单 | 含对方资质核验记录、授权委托书、评审记录 |

## 第 7 条　附则

**7.1** 本表与《合同管理办法》不一致的，以《合同管理办法》为准；本表就审批层级的专门规定优先适用。

**7.2** 本表版本 V1.6，自 2026-01-01 起生效，V1.5 同时废止。

**7.3** 本表由法务部负责解释，修订须经总经理办公会审议通过。
