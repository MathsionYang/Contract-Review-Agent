# 采购管理制度（V3.2）

## 第一章　总则

**第 1.1 条（目的）** 为规范公司采购行为，控制采购成本与法律风险，保障采购质量与交付进度，防范廉洁风险，依据《中华人民共和国民法典》《中华人民共和国招标投标法》及公司章程，制定本制度。

**第 1.2 条（适用范围）** 本制度适用于公司及各分子公司以任何资金来源实施的货物、工程、服务采购活动，包括设备购置、原辅材料、软件开发、技术服务、外包服务、房屋租赁等。

**第 1.3 条（基本原则）**
1. **合规原则**：采购活动应符合法律法规及本制度要求，不得拆分项目规避审批；
2. **经济原则**：同等条件下择优选取性价比最高的供应商；
3. **公开原则**：达到限额标准的采购应公开征集供应商，不得指定；
4. **制衡原则**：需求提出、采购执行、验收、付款四个环节不得由同一人完成；
5. **留痕原则**：采购全过程应形成书面或电子记录并归档。

**第 1.4 条（术语）**
- **需求部门**：提出采购需求并承担技术责任与使用责任的部门；
- **采购部**：组织实施采购活动、管理供应商、签订合同的部门；
- **重大采购**：单项金额 ≥ 500 万元的采购；
- **重要采购**：单项金额在 100 万元（含）至 500 万元之间的采购；
- **一般采购**：单项金额在 5 万元（含）至 100 万元之间的采购；
- **小额采购**：单项金额低于 5 万元的采购。

## 第二章　组织与职责

**第 2.1 条（职责分工）**

| 角色 | 主要职责 | 禁止事项 |
| --- | --- | --- |
| 需求部门 | 编制需求说明与技术规格书；参与技术评审；组织验收；提出付款申请 | 不得直接与供应商议价、不得指定供应商 |
| 采购部 | 组织采购、比价、谈判；供应商准入与评价；起草与签订合同；跟踪交付 | 不得参与验收结论的最终认定 |
| 财务部 | 预算审核；付款审核与执行；发票与税务合规 | 不得在无验收单的情况下付款 |
| 法务部 | 合同审查；争议处理；本制度与合同管理办法的维护 | 不得替代业务部门作商业决策 |
| 内审部 | 采购合规审计；异常采购专项检查 | — |
| 技术委员会 | 重大采购的技术方案评审 | — |

**第 2.2 条（不相容岗位分离）** 下列岗位不得由同一人担任：
1. 采购需求提出与采购执行；
2. 采购执行与验收确认；
3. 合同审查与合同签订；
4. 付款审批与付款执行。

## 第三章　采购方式与限额

**第 3.1 条（采购方式）**

| 方式 | 适用条件 | 供应商数量要求 |
| --- | --- | --- |
| 公开招标 | 重大采购；或技术方案可充分描述、市场竞争充分 | ≥ 3 家投标 |
| 邀请招标 | 潜在供应商数量有限或技术要求特殊 | ≥ 3 家受邀 |
| 竞争性谈判 | 技术方案需与供应商反复沟通后确定 | ≥ 3 家参与 |
| 询比价 | 规格标准统一、市场供应充足的通用货物 | ≥ 3 家报价 |
| 单一来源 | 见第 3.4 条 | 1 家 |

**第 3.2 条（限额标准）**

| 采购类型 | 金额区间 | 采购方式 | 审批层级 |
| --- | --- | --- | --- |
| 重大采购 | ≥ 500 万元 | 公开招标（原则） | 总经理办公会 |
| 重要采购 | 100 万（含）–500 万 | 邀请招标 / 竞争性谈判 | 分管副总 + 总经理 |
| 一般采购 | 5 万（含）–100 万 | 竞争性谈判 / 询比价 | 采购部负责人 + 分管副总 |
| 小额采购 | < 5 万元 | 询比价（可简化） | 采购部负责人 |

**第 3.3 条（小额采购简化程序）** 单项金额低于人民币 **5 万元** 的采购，可适用下列简化程序：
1. 取得 **2 家以上**供应商报价即可；
2. 合同可采用订单、确认单等简式文本，但**必须包含**：标的、数量、单价、交付时间、验收标准、付款条件、违约责任、争议解决；
3. **不得**约定全额预付，付款比例与节奏按第 9.2 条执行（可按比例缩放，但须保留不低于 20% 的验收后付款）；
4. 同一供应商在同一年度内的同类小额采购累计金额达到 5 万元的，**不得继续拆分为小额采购**，应合并按一般采购程序办理。

**第 3.4 条（单一来源采购）** 仅在下列情形可适用单一来源方式，且必须取得总经理批准：
1. 只能从唯一供应商处采购（需附市场调研说明）；
2. 发生不可预见的紧急情况，无法从其他供应商采购；
3. 必须保证与原采购项目的一致性或服务配套，且更换供应商将造成显著不经济；
4. 涉及专利、专有技术或原厂授权，无替代来源。

单一来源采购须在采购记录中书面说明理由，并接受内审部抽查。

**第 3.5 条（禁止拆分）** 严禁将应整体实施的采购项目拆分为多个小额项目以规避审批权限或采购方式要求。内审部通过"同一供应商 + 同一品类 + 同一预算年度"的组合筛查进行监控。

## 第四章　供应商准入与管理

**第 4.1 条（准入条件）** 供应商应同时具备：
1. 依法注册、存续经营，营业执照在有效期内；
2. 具备履行合同所需的资质、许可、认证（如涉及特种设备、软件、信息安全等）；
3. 未被列入国家企业信用信息公示系统的**经营异常名录或严重违法失信名单**；
4. 未被列入**失信被执行人名单**；
5. 近三年无因产品质量、交付违约引发的重大诉讼且败诉；
6. 通过公司的**廉洁承诺**（签署《供应商廉洁承诺书》）。

**第 4.2 条（准入审查材料）** 供应商应提交：
1. 营业执照（核对**统一社会信用代码**，须为 18 位且与公示信息一致）；
2. 法定代表人身份证明及授权委托书（由代理人签署合同时）；
3. 相关资质证书、体系认证证书；
4. 近两年财务报表或审计报告（重大采购适用）；
5. 主要客户及业绩清单；
6. 廉洁承诺书；
7. 银行开户证明。

采购部应通过"国家企业信用信息公示系统""中国执行信息公开网""中国裁判文书网"进行**独立核验**，不得仅凭供应商提供的材料通过。

**第 4.3 条（供应商分级）**

| 等级 | 条件 | 采购政策 |
| --- | --- | --- |
| A 级（战略） | 连续 3 年履约良好、无质量事故、评价 ≥ 90 分 | 可参与单一来源采购；可给予预付款优惠（不超过第 9.2 条上限） |
| B 级（合格） | 履约正常、评价 75–89 分 | 正常参与各类采购 |
| C 级（观察） | 出现轻微违约或评价 60–74 分 | 限制参与重要及以上采购，须提供履约担保 |
| D 级（淘汰） | 评价 < 60 分，或发生重大违约、行贿、造假 | 列入黑名单，3 年内不得参与 |

**第 4.4 条（黑名单）** 发生下列情形之一的，列入黑名单并报法务部备案：
1. 提供虚假资质、业绩或财务资料；
2. 商业贿赂或与公司员工存在未申报的利益关系；
3. 中标后无正当理由拒绝签约或拒不履行；
4. 产品质量问题造成公司损失且拒绝赔偿；
5. 发生转包、违法分包。

## 第五章　采购需求与预算

**第 5.1 条（需求提出）** 需求部门应提交《采购需求申请单》，内容包括：采购标的与用途、技术规格与性能指标、数量与交付时间、估算金额、预算科目与余额、验收标准建议。

**第 5.2 条（技术规格编制要求）** 技术规格书应当：
1. 以**性能指标**为主要描述方式，避免出现指向特定品牌的排他性描述（原厂配件除外）；
2. 明确可量化的验收指标（如能耗、精度、节拍、稳定性等）；
3. 随采购文件一并作为合同附件，并在合同中约定其为合同不可分割的组成部分。

**第 5.3 条（预算控制）** 无预算或超预算的采购不得启动。确需调整预算的，按公司预算管理办法另行审批。

---

## 第六章　请购与审批

**第 6.1 条（审批流程）** 一般及以上采购按下列流程执行：

```
需求部门提出 → 部门负责人审核 → 采购部核价与方式建议
   → 分管副总审批 → 〔达到重要采购层级〕总经理审批
   → 法务部合同审查 → 签署 → 履约 → 验收 → 付款
```

**第 6.2 条（审批时限）** 各审批环节应在 **2 个工作日**内完成；超时未处理的，系统自动提醒并向上一级通报。

**第 6.3 条（禁用条款）** 采购立项与审批文件中**不得**出现指定供应商、指定品牌（第 5.2 条除外）、暗示性倾向表述。

---

## 第七章　合同签订

**第 7.1 条（合同签订原则）** 一般及以上采购**必须签订书面合同**。合同签订应遵守《合同管理办法》（POL-CON）。

**第 7.2 条（签约时限）** 应在中标/成交通知发出后 **15 个工作日**内完成合同签署；逾期未签的，应重新确认供应商意愿与价格有效性。

**第 7.3 条（合同必备条款）** 采购合同必须包含下列条款，缺项的应退回补充：
1. 标的、规格型号、数量、单价与总价；
2. 质量标准与验收标准（含验收期限、验收方式、不合格处理）；
3. 交付时间、地点、运输与风险转移；
4. 付款条件、比例、节点与发票要求；
5. 质保期与质保金；
6. 违约责任（双向）；
7. 知识产权与数据条款（涉及软件、数据采集的必须约定）；
8. 保密条款（双向）；
9. 廉洁与反商业贿赂条款；
10. 不可抗力；
11. 合同变更、转让与解除；
12. 争议解决方式；
13. 附件清单与效力顺序。

**第 7.4 条（合同审查）** 合同签署前必须经法务部审查。法务部审查意见分为三级：

| 意见类型 | 含义 | 处理 |
| --- | --- | --- |
| 通过 | 无重大风险 | 可直接签署 |
| 修改后签署 | 存在需修改条款 | 修改后经法务确认可签署 |
| 不建议签署 | 存在 P0 级风险且对方拒绝修改 | 提交分管副总与总经理决策 |

**第 7.5 条（用印管理）** 合同用印按《合同管理办法》第 8 章执行。用印须凭完整审批流程记录，不得空白用印、不得先盖章后补审批。

---

## 第八章　履约与验收

**第 8.1 条（履约跟踪）** 采购部应建立交付跟踪表，在交付期届满前 **10 日**向供应商发出交付确认函；预计延期的，应取得供应商书面说明并评估影响。

**第 8.2 条（验收组织）** 验收由需求部门组织，采购部、技术委员会（重大采购）参加。验收应当：
1. 在合同约定的**验收期限内**完成；
2. 依据合同约定的验收标准逐项测试并记录**原始数据**；
3. 形成《验收报告》，载明验收结论、存在问题、整改要求与期限；
4. 对不合格项，应在**异议期内**书面通知供应商。

**第 8.3 条（验收禁止事项）**
1. **不得**以"设备已进场""已签收"替代实质验收；
2. **不得**在未完成测试的情况下签署验收合格文件；
3. **不得**接受"验收合格后不再主张质量责任"的约定——**质量保证期内的质量问题仍可依合同主张**（参见 `LAW-CIVIL-621` 但书）。

**第 8.4 条（超期未验收）** 因公司原因导致超期未验收的，采购部应在期限届满前书面告知供应商并说明新的验收安排，**避免因怠于通知而触发"视为验收合格"**（`LAW-CIVIL-621`）。

## 第九章　付款管理

**第 9.1 条（付款前提）** 付款必须同时满足：
1. 已签订有效合同（小额采购可为订单）；
2. 已取得合同约定的交付凭证；
3. 已达付款节点对应的验收结论；
4. 已取得**合规发票**（见第 9.5 条）；
5. 已完成对应层级的付款审批。

**第 9.2 条（付款节奏）** 采购合同原则上按下列节奏约定付款，**预付款比例不得超过合同总价的 30%**：

| 节点 | 比例 | 说明 |
| --- | --- | --- |
| 合同签订后 | ≤ 30% | 可作为预付款；**必须**取得预付款保函或对方提供等价担保（金额 ≥ 100 万元时） |
| 全部到货并初步验收合格 | ≤ 60%（含预付累计） | 累计支付不超过 90% |
| 最终验收合格 | 至 90%–95% | — |
| 质保期满且无未决质量问题 | 5%–10% | 质保金，见第 9.3 条 |

**禁止约定全额预付**（100% 于签约后支付）。确因对方要求且已取得**全额预付款保函**的，须经分管副总与财务负责人共同批准，并在审批记录中说明原因。

**第 9.3 条（质保金）** 
1. 质保金比例不低于合同总价的 **5%**，关键设备建议 10%；
2. 质保金在质保期满且无未决质量问题后 **30 日内**无息退还；
3. 以**质保期银行保函**或质量保证保险替代质保金的，经财务部认可后可免于预留。

**第 9.4 条（付款时限）** 财务部应在收到完整付款申请及发票后 **5 个工作日**内完成审核，**10 个工作日**内付款。

**第 9.5 条（发票要求）**
1. 供应商应开具**增值税专用发票**，税率与合同约定一致；
2. 发票不合规（品名、金额、税率错误，或无法认证）的，供应商应在 **5 个工作日**内换开，付款期相应顺延；
3. 合同中**不得**约定"公司不得以发票事宜拒绝或延迟付款"之类剥夺抗辩权的表述。

**第 9.6 条（付款禁止事项）**
1. 禁止向合同约定账户以外的第三方账户付款；
2. 禁止在未取得对方书面确认的情况下变更收款账户；
3. 禁止以现金方式支付超过 1 万元的货款；
4. 禁止在争议未解决的情况下支付争议部分款项（可先付无争议部分）。

## 第十章　廉洁与监督

**第 10.1 条（廉洁要求）** 公司参与采购活动的人员：
1. 不得收受供应商的现金、有价证券、礼品、佣金、回扣；
2. 不得接受可能影响公正履职的宴请、旅游、娱乐安排；
3. 不得在供应商处兼职或持有权益；
4. 不得向供应商泄露其他供应商的报价、技术方案等竞争性信息；
5. 与供应商存在亲属或其他利益关系的，应主动申报并回避。

**第 10.2 条（廉洁条款入约）** 采购合同必须包含廉洁与反商业贿赂条款，明确禁止事项、申报义务与违约后果（详见 `POL-CON-6.11`）。

**第 10.3 条（监督方式）** 内审部每年至少开展一次采购专项审计，重点检查：单一来源采购、拆分采购、超限额采购、价格异常、黑名单供应商交易。

**第 10.4 条（违规处理）** 违反本制度的，按公司员工奖惩规定处理；涉嫌违法犯罪的，移送司法机关。

## 第十一章　档案管理

**第 11.1 条（归档范围）** 每笔采购应形成完整卷宗：需求申请单、审批记录、采购文件、报价文件、评审记录、合同及附件、变更协议、交付与验收记录、付款凭证、发票、往来函件。

**第 11.2 条（保管期限）** 合同履行完毕后**至少保存 10 年**；涉及不动产、重大设备的保存 **20 年**；发生争议的，保存至争议终结后 5 年。

**第 11.3 条（电子档案）** 电子签署的合同应保存完整的签署证据包（含实名认证记录、时间戳、存证证书、操作日志），保存期限同纸质档案。

## 第十二章　附则

**第 12.1 条（与合同管理办法的关系）** 本制度与《合同管理办法》（POL-CON）就合同签订、审批、用印等事项的规定不一致的，以《合同管理办法》为准；本制度另有规定的采购程序性事项，从其规定。

**第 12.2 条（版本管理）** 本制度版本 V3.2，自 2026-01-01 起生效，V3.1 同时废止。历史版本由行政部留存，供追溯审查依据使用。

**第 12.3 条（解释与修订）** 本制度由采购部负责解释，修订须经总经理办公会审议通过。法务部应在法律法规或公司业务发生重大变化时提出修订建议，**至少每 2 年复核一次**。

**第 12.4 条（生效）** 本制度经总经理办公会审议通过后公布施行。
