# 确定性规则集 · 商务与法务阈值

> **关于阈值的性质**：本规则集的阈值**不是法律硬性规定**，而是"司法实践可接受区间"与"企业风险偏好"的交集。因此：
> - 阈值**可由企业调整**，但调整须经审批（见 `KB-INDEX` 第七节）；
> - 命中阈值**不等于条款无效**，只是触发风险提示与修改建议；
> - 突破阈值且不修改的，须在审批记录中说明理由并留痕。
>
> 这一点必须写进工具的提示语，避免使用者误以为"超过阈值即违法"。

## 二、逐条判定逻辑

### 一）付款类

#### RULE-BIZ-001　预付款比例上限

| 项 | 内容 |
| --- | --- |
| 阈值 | 预付款 ≤ 合同总价 **30%**；≥ 100% 直接判 P0 |
| 判定逻辑 | 抽取"合同签订后 N 日内支付 X%（金额）"类表述，计算**在无对应交付/验收前提下的累计付款比例**；若存在"预付 A% + 到货付 B% + 验收付 C% + 质保金 D%"，则取 A 与"到货前累计支付比例"中的较大者 |
| 命中动作 | 触发前累计付款 > 30% → **P1**；= 100%（且不挂钩交付/验收） → **P0** |
| 依据 | `POL-PUR-9.2`；`LAW-CIVIL-626`（付款方式由约定，故风险靠制度管控） |
| 豁免情形 | ① 金额 ≤ 5 万元的小额采购（`POL-PUR-3.3`）；② 已取得**预付款保函**或同等担保；③ 对方为集团内关联企业且经 `POL-AUTH-4.1` 特批。命中豁免的降级为 P3 并提示"已豁免，请留存审批依据" |

#### RULE-BIZ-002　付款与交付验收挂钩

| 项 | 内容 |
| --- | --- |
| 阈值 | 合同总价的**至少 60%** 应与交付、安装调试、验收节点挂钩 |
| 判定逻辑 | ① 抽取全部付款节点及其触发条件；② 分类为"前置型"（签约、开票、下单）与"后置型"（到货、安装完成、验收合格、质保期满）；③ 计算后置型付款占比；④ 检查是否设置**质保尾款** |
| 命中动作 | 后置型占比 < 60% → **P1**；无任何后置型节点 → **P0** |
| 依据 | `POL-PUR-9.2` |
| 豁免情形 | 到货即验收的低价值标准品采购，可不设质保尾款，但保留 30% 到货款 |

#### RULE-BIZ-003　质保金比例

| 项 | 内容 |
| --- | --- |
| 阈值 | 质保金 ≥ 合同总价 **5%**，质保期满且无未决质量问题后无息退还 |
| 判定逻辑 | 检索是否存在与质保期挂钩的预留款；存在则计算比例与退还条件 |
| 命中动作 | 未约定质保金 → **P1**；比例 < 5% → **P1**；约定"不退还" → **P0**（变相涨价） |
| 依据 | `POL-PUR-9.3` |
| 豁免情形 | 已取得**质保期银行保函**或第三方质量保证保险的，可不设质保金 |

### 二）违约责任类

#### RULE-BIZ-004　逾期付款违约金上限

| 项 | 内容 |
| --- | --- |
| 阈值 | 日费率 ≤ **0.05%**（年化 18.25%）；≥ 0.5%（年化 182.5%）判 P0 |
| 判定逻辑 | 提取日费率的全部表述形式并归一化：`万分之X` / `X‰` / `X%` / `日千分之X`；计算年化值 = 日费率 × 365 |
| 命中动作 | > 0.05% → **P1**；≥ 0.5% → **P0**；两类并存时按最高等级输出 |
| 依据 | `LAW-CIVIL-585`（过分高于损失可调减）；《全国法院贯彻实施民法典工作会议纪要》第 11 条（超过损失 30% 一般认定过分高于）；`POL-CON-6.4` |
| 归一化换算表 | 万分之五 = 0.05% = 年化 18.25%；万分之五十 = 0.5% = 年化 182.5%；千分之一 = 0.1% = 年化 36.5% |

#### RULE-BIZ-005　逾期交货违约金下限

| 项 | 内容 |
| --- | --- |
| 阈值 | 日费率 ≥ **0.03%**；上限封顶 ≥ 合同总价 10% |
| 判定逻辑 | 同 004 的归一化逻辑；另检查计算基数（合同总价 / 逾期部分货款 / 未交付部分价值） |
| 命中动作 | < 0.03% → **P1**；封顶 < 10%（如 1%） → **P1** |
| 依据 | `POL-CON-6.4`（违约救济应具有实际约束力） |
| 误报提示 | 若合同同时约定了**替代采购条款**与**解除权**，低违约金可由其他救济弥补，降级为 P2 |

#### RULE-BIZ-006　双向违约金对称度

| 项 | 内容 |
| --- | --- |
| 阈值 | 双方同类违约的日费率倍差 ≤ **5 倍**（按对甲方不利的方向计算） |
| 判定逻辑 | 取"甲方逾期付款日费率"与"乙方逾期交货日费率"，计算比值 R = 高值 / 低值 |
| 命中动作 | R > 5 → **P1**，输出"双向倍差 R 倍，其中对我方不利方向为 X"；R > 50 → **P0** 候选（与 004 联合判定） |
| 依据 | `LAW-CIVIL-585`、`POL-CON-6.4`；《民法典》第 6 条公平原则 |
| 豁免情形 | 双方义务性质本质不同（如一方为金钱债务、一方为交付债务），倍差 5 倍以内属正常商业安排 |

#### RULE-BIZ-007　违约金总额封顶

| 项 | 内容 |
| --- | --- |
| 阈值 | 封顶比例 ≥ **10%**，或不做封顶 |
| 判定逻辑 | 检索"违约金总额不超过合同总价的 X%"表述 |
| 命中动作 | < 10% → **P1**；同时检查是否存在"违约金与赔偿损失不可并用"的表述，若并用被排除则升为 **P0** |
| 依据 | `POL-CON-6.4` |
| 误报提示 | 封顶仅适用于**迟延履行**违约金、而根本违约另设责任时，属合理设计，不判缺陷 |

#### RULE-BIZ-008　赔偿责任限额

| 项 | 内容 |
| --- | --- |
| 阈值 | 限额应 ≥ 合同总价 **100%**，且必须列明**不适用限额的例外情形** |
| 判定逻辑 | ① 检出限额条款；② 计算限额占合同总价比例；③ 检查是否包含以下例外：人身损害、故意或重大过失、知识产权侵权、违反保密义务、数据泄露 |
| 命中动作 | 限额 < 100% → **P1**；限额 ≤ 20% 且无例外 → **P0**；有例外但限额 ≤ 20% → **P1** |
| 依据 | `LAW-CIVIL-506`（造成人身损害、因故意或重大过失造成财产损失的免责条款**无效**）；`LAW-CIVIL-497`（格式条款不合理减轻己方责任的无效）；`POL-CON-6.5` |
| 判定要点 | **这是本规则集中最需要"跨条款推理"的规则**：限额条款与免责条款往往分处两条，必须合并判断。单独的"赔偿责任限额 5%"看似只是一个商业条件，加上"不承担间接损失、可得利益、停产损失"后才构成完整的责任排除结构 |

### 三）交付、质量与验收类

#### RULE-BIZ-009　不可抗力范围

| 项 | 内容 |
| --- | --- |
| 阈值 | 不可抗力列举项必须同时满足"不能预见、不能避免、不能克服"三要件 |
| 判定逻辑 | 与商业风险黑名单比对，命中即判违规：`{原材料价格上涨, 价格波动, 汇率波动, 上游供应商产能不足, 供应链中断, 物流延误, 政策调整*}` <br>（* 政策调整需区分：征收、禁令属不可抗力；产业政策、补贴退坡属商业风险） |
| 命中动作 | 含黑名单事项 → **P1**；同时约定"无需提供证明" → **P1**；同时约定"顺延后仍需付款" → **P1**（三条可合并计为一次 P1，但须在报告中全部列出） |
| 依据 | `LAW-CIVIL-590`（不可抗力的免责以三要件为限；应当及时通知并在合理期限内**提供证明**；迟延履行后发生不可抗力的不免责） |
| 豁免情形 | 列举项前有"包括但不限于"且**未穷尽列举商业风险**时，仅提示不报警；列举项明确写"经双方确认的重大市场异常"等模糊表述时判 P2 |

#### RULE-BIZ-010　风险转移与交货方式一致

| 项 | 内容 |
| --- | --- |
| 阈值 | 风险转移时点必须与交货方式的商业实质一致 |
| 判定逻辑 | ① 识别交货方式：`送货上门 / 自提 / 代办运输 / 未约定`；② 识别风险转移条款的时点；③ 一致性矩阵判定（见下表） |
| 命中动作 | 矩阵判定为"矛盾" → **P1** |
| 依据 | `LAW-CIVIL-604`（交付主义）、`LAW-CIVIL-607`（仅在特定情形下交付承运人即转移） |
| 判定要点 | 引用 `LAW-CIVIL-607` 时须注意其**适用前提**：本条针对的是"约定运送至指定地点并交付承运人"或"未约定交付地点"两种情形。若合同已明确约定卖方送货至买方现场，则不适用本条，约定"交付承运人后风险转移"背离交易实质 |

**一致性矩阵**

| 交货方式 | 合理风险转移时点 | 矛盾情形 |
| --- | --- | --- |
| 卖方送货至买方现场 | 送达买方现场 / 验收合格 | 约定"交付承运人时转移" |
| 买方自提 | 提货时 | 约定"运抵目的地时转移" |
| 卖方代办运输、运费卖方承担 | 送达买方现场 | 约定"交付承运人时转移" |
| 未约定交付地点 | 交付第一承运人 | 无（符合 607 条） |

#### RULE-BIZ-011　验收期与拟制验收

| 项 | 内容 |
| --- | --- |
| 阈值 | 验收期 ≥ **7 个工作日**（简单设备）/ **30 日**（成套系统、需安装调试的设备） |
| 判定逻辑 | ① 提取约定的验收期限；② 按标的物复杂度选择阈值档；③ 检查是否存在"逾期未提异议视为验收合格"类拟制条款；④ 检查异议期与验收期是否自相冲突 |
| 命中动作 | 期限低于档位阈值 → **P1**；拟制验收条款 + 期限低于阈值 → **P1**（叠加，须说明"短期限 + 拟制合格"的组合导致异议权实际落空）；两处验收期不一致 → **P1** |
| 依据 | `LAW-CIVIL-620`、`LAW-CIVIL-621`（拟制合格以约定检验期限为前提，期限应合理）；`POL-CON-6.6` |
| 误报提示 | **本条是误报高发区**。约定 15 日验收期 + 拟制条款属行业常见做法，**不应判高风险**。必须结合标的物复杂度判断，不能只抓"视为合格"关键词 |

#### RULE-BIZ-012　质保期起算点与年限

| 项 | 内容 |
| --- | --- |
| 阈值 | 起算点应为**最终验收合格之日**；年限 ≥ 12 个月（关键设备建议 24 个月） |
| 判定逻辑 | ① 提取质保期年限与起算点；② 检查"出厂日""发货日""到货日""验收合格日"四类起算点；③ 检查全文质保期年限是否唯一 |
| 命中动作 | 起算点为"出厂日/发货日" → **P1**（运输与安装期被计入质保）；年限 < 12 个月 → **P1**；两处年限冲突 → **P1** |
| 依据 | `LAW-CIVIL-621`（有质量保证期的适用质量保证期）；`POL-CON-6.7` |

### 四）争议解决与救济类

#### RULE-BIZ-013　争议解决方式唯一性

| 项 | 内容 |
| --- | --- |
| 阈值 | 仲裁与诉讼**只能择一**，且仲裁机构须唯一、明确 |
| 判定逻辑 | ① 检索是否存在仲裁条款与诉讼条款同时出现；② 若为仲裁，检查机构名称是否唯一（"某地仲裁委员会"属不明确）；③ 检查终局性表述是否自相矛盾（"终局裁决"与"可申请重新审理"并存） |
| 命中动作 | 或裁或审并存 → **P0**（仲裁协议无效，管辖回归法定）；仲裁机构不唯一 → **P1**；终局性表述矛盾 → **P1** |
| 依据 | `LAW-ARB-16`、`LAW-ARB-18`；仲裁法司法解释关于"或裁或审条款无效"的规则 |
| 判定要点 | 仲裁机构所在地本身不导致条款无效（若该地仅有一家机构），但**异地仲裁的维权成本应作为独立风险提示**，由 `RULE-BIZ-014` 处理，二者不可混淆 |

#### RULE-BIZ-014　管辖地对等性

| 项 | 内容 |
| --- | --- |
| 阈值 | 优先约定**甲方所在地**或**合同履行地（收货地）**法院；约定在对方所在地时须有对价 |
| 判定逻辑 | ① 识别约定管辖地；② 与甲方住所地、合同履行地比对；③ 检查是否单向锁定（仅约定一方所在地） |
| 命中动作 | 约定仅对方所在地 → **P1**（须说明异地诉讼成本：差旅、代理、执行难度）；约定与争议无实际联系的地点 → **P1** 并提示条款可能无效 |
| 依据 | `LAW-CIVPRO-35`；`LAW-CIVPRO-EXPL-18`（合同履行地通常为收货地，即甲方所在地，属甲方天然优势，不应轻易放弃） |

### 五）权属、保密与合规类

#### RULE-BIZ-015　知识产权权属

| 项 | 内容 |
| --- | --- |
| 阈值 | ① 基于甲方需求定制开发的部分及集成方案归**甲方**；② 甲方获得的软件许可应为**永久、不可撤销、可内部使用**；③ 许可期限不得与合同存续绑定 |
| 判定逻辑 | ① 检索 IP 归属条款；② 判断标的是标准产品还是定制成果；③ 检查许可的期限、范围、可否转让；④ 检查是否约定"合同终止后许可自动终止" |
| 命中动作 | 定制成果归对方 → **P1**；许可非永久 → **P1**；约定合同终止后许可终止 → **P1**（已付全款仍可能无法继续使用） |
| 依据 | `POL-CON-6.8` |
| 误报提示 | 标准软件的许可期限与厂商产品生命周期绑定属行业惯例，若不涉及定制开发，**不应判高风险**，改判 P2 并提示约定"至少 10 年或产品生命周期内" |

#### RULE-BIZ-016　数据权属与使用范围

| 项 | 内容 |
| --- | --- |
| 阈值 | ① 甲方业务数据、产线数据归甲方；② 对方仅可为履行合同目的处理；③ 禁止"用于产品优化、数据分析、商业用途"等开放式目的 |
| 判定逻辑 | ① 检索数据条款；② 检查是否存在数据权属约定；③ 检查数据使用目的是否封闭（列举式）；④ 检查合规要素齐备性（见 `LAW-03` 第 4.3 节清单） |
| 命中动作 | 数据可无偿商用 → **P1**；无权属约定 → **P1**；缺委托处理要素（目的、期限、方式、种类、保护措施、删除义务、禁止转委托）→ **P1**；缺安全事件告知义务 → **P1** |
| 依据 | `LAW-DSL-27`、`LAW-DSL-29`、`LAW-DSL-32`、`LAW-PIPL-13`、`21`、`51`、`55` |

#### RULE-BIZ-017　保密义务双向性

| 项 | 内容 |
| --- | --- |
| 阈值 | 保密义务**双向对称**，且有明确期限（建议合同终止后 5 年）与对等违约责任 |
| 判定逻辑 | ① 检查保密条款的义务主体是否双方；② 检查是否明确保密期限；③ 检查是否约定违约后果；④ 检查保密信息范围是否单向定义 |
| 命中动作 | 单向保密 → **P1**；无期限（仅"终止后继续有效"） → **P2**；无违约后果 → **P2** |
| 依据 | `LAW-CIVIL-501`（订约中知悉的商业秘密不得泄露，无论合同是否成立）；`POL-CON-6.9` |

#### RULE-BIZ-018　合同转让限制

| 项 | 内容 |
| --- | --- |
| 阈值 | 任何一方**未经对方书面同意不得转让**合同权利义务 |
| 判定逻辑 | 检索转让条款，检查是否单向允许对方自由转让 |
| 命中动作 | 对方可单方转让义务 → **P1** |
| 依据 | `LAW-CIVIL-555`（经对方同意方可一并转让） |
| 误报提示 | 允许对方转让**债权**（如应收账款保理）属正常商业安排，不判缺陷；本条针对的是**义务的概括转让** |

#### RULE-BIZ-019　税负与发票要素

| 项 | 内容 |
| --- | --- |
| 阈值 | ① 全篇对价款的含税/不含税定性**必须唯一**；② 发票要素齐备：类型（增值税专用发票）、税率、开具时限、**不合规时的换开义务与付款顺延** |
| 判定逻辑 | ① 抽取所有含税性表述，检查一致性；② 检查发票条款四要素；③ 检查是否存在"不得以发票事宜拒付"类剥夺抗辩权的表述 |
| 命中动作 | 含税与不含税表述并存 → **P0**（重复计价风险）；发票要素缺失 → **P2**；剥夺发票抗辩权 → **P2**；税负变化单方由甲方承担 → **P2** |
| 依据 | `POL-CON-6.10`；税务合规与发票管理要求 |
| 判定要点 | **跨条款比对是必须的**：含税定性往往写在"价款条款"，而税费承担写在靠后的"税务条款"，单条阅读均无异常 |

### 六）履约结构与治理类

#### RULE-BIZ-020　解除权对等性

| 项 | 内容 |
| --- | --- |
| 阈值 | 双方触发解除的条件应具有可比性；任一方均不得被剥夺法定解除权 |
| 判定逻辑 | ① 提取双方的解除条件、违约金、赔偿范围；② 对照比较宽严程度；③ 检查是否排除一方的法定解除路径（表现为"只能要求继续履行"） |
| 命中动作 | 条件或后果显著不对等 → **P1**；排除一方救助手段 → **P1**；约定"对方逾期 N 日即可解除 + 高额违约金 + 全部损失"而反向无对应权利 → **P1** |
| 依据 | `LAW-CIVIL-562`、`563`、`566`；`POL-CON-6.5` |

#### RULE-BIZ-021　数量变更的单价锁定

| 项 | 内容 |
| --- | --- |
| 阈值 | 约定数量可增减的，必须同时约定：① 单价不变；② 增减幅度上限；③ 总价按实结算的口径 |
| 判定逻辑 | 检查"暂定数量""可增减""按实结算"表述是否与固定单价、调价机制配套 |
| 命中动作 | 数量可增减但未锁单价 → **P2**；与"价格固定不调整"条款并存而未说明关系 → **P2** |
| 依据 | `POL-CON-6.2` |

#### RULE-BIZ-022　廉洁与反商业贿赂条款

| 项 | 内容 |
| --- | --- |
| 阈值 | 必须包含：① 禁止提供/索取不正当利益的定义范围（礼品、宴请、旅游、回扣、关联交易）；② 申报与审计配合义务；③ 违约后果（解除权 + 违约金 + 赔偿） |
| 判定逻辑 | 检查条款是否存在、要素是否齐备 |
| 命中动作 | 完全缺失 → **P1**；仅一句原则表述、无定义与后果 → **P1** |
| 依据 | 《反不正当竞争法》关于禁止商业贿赂的规定；`POL-CON-6.11` |
| 误报提示 | 小额采购（≤5 万元）可适用简化条款，但仍需保留解除权约定 |

## 三、等级判定与降级规则

### 3.1 等级优先级

同一位置命中多条规则时，按最高等级输出，但**须列出全部命中规则**：

```
位置：第四条第 4.1 款
命中：RULE-BIZ-001（P0）、RULE-BIZ-002（P0）、RULE-BIZ-003（P1）
输出等级：P0
输出内容：3 条规则全部列出，附各自阈值与建议
```

### 3.2 降级条件

命中规则后，若存在下列情形，可降一级并注明理由：

| 降级条件 | 说明 | 须注明 |
| --- | --- | --- |
| 已提供担保或保函 | 预付款保函、履约保函、质保保函 | 保函编号与有效期 |
| 金额在豁免区间 | 依据 `POL-PUR-3.3` 的小额豁免 | 豁免条款号 |
| 已通过特批 | 有 `POL-AUTH` 规定的完整审批记录 | 审批单号 |
| 存在替代救济 | 如低违约金 + 替代采购权 + 解除权 | 替代条款位置 |

**降级不得由工具自动完成**——工具只负责识别降级条件的**存在性**并提示，是否降级由审批人决定并留痕。

### 3.3 升级规则

存在下列情形时，在最高等级基础上标注"**叠加风险**"，提示审批人该位置存在**组合型风险**：

- 同一位置命中 ≥3 条 P0/P1 规则
- 存在跨条款相互配合形成的风险结构（如"低违约金封顶" + "排除间接损失" + "责任限额"三者组合）
- 条款存在内部矛盾且矛盾方向一致性指向同一方不利
